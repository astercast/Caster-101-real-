## Bridge Pairings (Chia ↔ Base)
Tokens with different names on each chain. Both must resolve to the same `pairingKey`.

| Chia id | Base id | Canonical key | Note |
|---------|---------|---------------|------|
| byc-chia | wiz-base | `wiz` | Bytecash ($BYC) = Wizard Bucks on Base |

All other tokens have matching id prefixes (e.g. `caster-chia` ↔ `caster-base` → key `caster`).

`HouseofRegardedSchizoEquestrians` (HORSE), and other meme tokens added as needed.
